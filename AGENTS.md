# LLM-and-transformer-structure-explained

Purpose: the notebook that builds GPT-2 in PyTorch, loads OpenAI's released weights and fine-tunes it on the five *A Song of Ice and Fire* books and then on question-and-answer pairs. A public repository of Karam Abu Mokh, shown on his portfolio (karamam.com).

## Files
- `README.md`: what the project is, the live demo link, the measured results, how to run it and the structure.
- `fine_tuning_GPT2.ipynb`: the whole pipeline from books to a fine-tuned model, saved without outputs. Never commit a real API key into it.
- `AGENTS.md`: this file.

## Folders
- `docs/`: the picture the README shows (its own `AGENTS.md` lists it).

## Rules
- Real numbers only. The results table in the README comes from the training reports of the continued fine-tuning, not from this notebook.
